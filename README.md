# 業務ワークスペース

タスクの整理、会議の記録、業務報告、文書の下書きに使う基本的なワークスペースです。追加のソフトウェアや API キーは不要です。

## 使い方

Codex に、目的と必要な情報を日本語で伝えてください。例えば次のように依頼できます。

- 「今週のタスクを優先順位順に整理して」
- 「このメモから議事録を作って。決定事項と担当者をまとめて」
- 「今日の作業内容から日報の下書きを作って」
- 「この文章を読みやすい社内向けの文書に直して」

`templates/` のひな形をコピーし、成果物を `documents/` に保存します。ファイル名の例は `2026-10-07-meeting.md` です。日付は利用者のタイムゾーンに合わせてください。

## ひな形

- [タスク一覧](templates/tasks.md)：優先度、担当、期限、進捗の整理
- [議事録](templates/meeting.md)：議題、決定事項、次の対応の記録
- [業務報告](templates/report.md)：実績、課題、次の予定の共有

## 環境

Markdown ファイルを扱う構成なので、依存関係のインストールやサーバーの起動は不要です。Git で変更を確認・管理できます。アプリケーションや自動テストはまだ含まれていません。
